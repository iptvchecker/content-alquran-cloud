# Al Quran Cloud original text resource mirror

Original complete JSON responses for en.pickthall (Marmaduke Pickthall) and
ar.muyassar (Al-Muyassar commentary), retrieved directly from Al Quran Cloud.
Publisher: https://alquran.cloud/ ; underlying source credits and edition metadata
are preserved inside the original responses. Each contains 114 surahs/6,236 ayahs.
Redistribution guidance: https://alquran.cloud/terms-and-conditions (14 June 2026).

These Islamic materials are mirrored for reuse, with no ownership claim, content
editing, or removal of publisher/translator attribution. No audio is mirrored here.
Source validators and exact SHA-256 hashes are retained in SOURCE.json and
CHECKSUMS.sha256. Retrieval dates are not presented as original publication dates.
Downloads from this public repository require no credentials.

Future changes must use new dated snapshots and a review branch. Never remove
older files automatically when upstream deletes or changes a resource. Preserve
app-pinned releases. App integration is a separate step; no app endpoint is changed.
